# ❤️ Heart Disease Prediction

A Machine Learning-based web application built using **Streamlit** that predicts the likelihood of heart disease based on patient health information.

## 🌐 Live Demo

🚀 **Try the application here:**

[Heart Disease Prediction App](https://heart-disease-predictions-1.streamlit.app/?utm_source=chatgpt.com)

## 📌 Project Overview

Heart Disease Prediction is a Machine Learning project designed to analyze patient health-related information and predict the possibility of heart disease.

The application provides a simple and interactive web interface built with **Streamlit**, making it easy for users to enter health information and receive predictions.

## ✨ Features

* ❤️ Heart Disease Prediction
* 🤖 Machine Learning Model
* 📊 Interactive Streamlit Dashboard
* 🩺 User-friendly Health Data Input
* ⚡ Fast Predictions
* 🌐 Deployed Web Application

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/AKASHPATEL-89/Heart-Disease-Prediction.git
```

### 2️⃣ Open the Project Folder

```bash
cd Heart-Disease-Prediction
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Streamlit Application

```bash
streamlit run app.py
```
